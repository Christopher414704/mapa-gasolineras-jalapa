# Mapa de Gasolineras de Jalapa

Sistema web para visualizar gasolineras sobre un mapa 3D de Jalapa y consultar sus precios de combustible.

## Tecnologías

- Node.js
- Express
- PostgreSQL
- PostGIS
- JavaScript
- Vite
- CesiumJS
- Docker

## Módulos principales

- Mapa 3D de Jalapa.
- Gestión de gasolineras.
- Precios por tipo de combustible.
- Autoservicio y servicio manual.
- Modelos 3D de gasolineras.
- Administración de precios.
- Historial y auditoría.
